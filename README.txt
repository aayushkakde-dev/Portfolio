AAYUSH PORTFOLIO REDESIGN — FILES FOR THE EXISTING NEXT.JS REPOSITORY

WHAT TO REPLACE
1. In your repository, replace src/app/page.tsx with the supplied page.tsx.
2. Replace src/app/layout.tsx with the supplied layout.tsx.
3. Copy src/app/portfolio.css into src/app/portfolio.css.
4. Keep your existing src/app/globals.css and all other files unchanged.

IMPORTANT: UPDATE THESE VALUES IN src/app/page.tsx BEFORE PUBLISHING
- LINKEDIN_URL: replace https://www.linkedin.com/in/your-linkedin-id/ with the real LinkedIn profile URL.
- EMAIL: replace your.email@example.com with the real email address.
- skills: check the starter skills list and remove/add skills to match the portfolio owner accurately.
- projects: currently empty on purpose. Add project name, description, technologies, and GitHub repository URL to the projects array once those details are ready.

RUN LOCALLY
Open the repository folder in VS Code and run:
  npm install
  npm run dev
Then open http://localhost:3000.

The header uses real anchor links (#overview, #projects, #skills, #contact); CSS smooth scrolling and top spacing are included. The hero uses a free-to-use Unsplash photo URL and a dark overlay for readability.
